# Project Demonstration Video

This directory is designated for the Cardinality assessment demonstration video.

## Usage & Placement

1. Place the local demonstration screen recording (e.g. `commit-demo.mp4`, maximum five minutes) in this directory or host it on an accessible platform (e.g., Loom, YouTube Unlisted, or Google Drive).
2. Update the root `README.md` under **Project Demonstration** by replacing `VIDEO_LINK_PLACEHOLDER` with the actual link or relative file path:
   ```markdown
   [Watch the Commit Project Demonstration](YOUR_VIDEO_LINK_OR_FILE_PATH)
   ```

> [!IMPORTANT]
> **GitHub File Size Restrictions:**
> - GitHub issues a warning for files larger than **50 MB** and blocks pushes containing individual files larger than **100 MB**.
> - If your video file is larger than 50–100 MB, host the video on a streaming/cloud platform and provide the URL in `README.md`, or compress the video to remain well below GitHub's limits.
